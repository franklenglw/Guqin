古琴减字谱编辑器V5.0 — 使用说明书
Guqin JianZiPu Editor V5.0 — User Manual

一、这是什么 / What Is This

本插件是一个 MuseScore 3 的停靠面板插件，用于在音符下方快速输入、修改、删除“古琴标记”。本插件基于 Noto Qin Jianzipu 字体（多标记版，带搜索）。所有古琴标记统一使用 Noto Qin Jianzipu 字体（思源琴黑）渲染，并以多行文本（Staff Text）的形式挂载在音符上。
This plugin is a dock panel for MuseScore 3. It lets you quickly insert, edit and delete Guqin marks below notes. This plugin is based on the Noto Qin Jianzipu font (multi-mark, with search). All Guqin marks are rendered with the Noto Qin Jianzipu font and attached to notes as multiline Staff Text elements.

一个古琴标记就是一段“代码”，该字体利用合字（Ligature）特性，通过字母和符号的组合拼凑出减字谱图形。插件负责把你的代码变成谱面上的减字图形。
Each Guqin mark is a piece of “code”. The font uses ligatures to combine letters and symbols into JianZiPu graphics. The plugin turns your code into the graphic on the score.

二、安装 / Installation

将插件文件夹放入 MuseScore 的插件目录（Windows 通常是 文档/MuseScore3/Plugins），重启 MuseScore，在菜单 插件 → 插件管理器 中启用本插件即可。
Put the plugin folder into your MuseScore plugin directory (on Windows usually Documents/MuseScore3/Plugins), restart MuseScore, then enable it in Plugins → Plugin Manager.

【重要提醒】若要正确显示减字，请务必先安装 Noto Qin Jianzipu 字体到系统字体目录。未安装字体将显示为乱码或原始代码。
[Important] To display the marks correctly, install the “Noto Qin Jianzipu” font into your system font directory first. Without the font, it will show gibberish or raw codes.

三、界面说明 / Interface

面板从上到下依次为：标题、操作按钮行（读取 / 输入框 / 修改 / 删除）、提示文字、“一键删除全部古琴标记”按钮、搜索行（常用标记 / 搜索 / 清空 / 条数）、代码列表。
From top to bottom the panel contains: the title, the action row (Read / input box / Apply / Delete), the hint text, the “Delete All Guqin Marks” button, the search row (Common Marks / Search / Clear / count), and the code list.

- 读取（Read）：读取当前选中音符上已有的全部古琴标记代码，填入输入框。
- Read: Reads all existing Guqin mark codes on the currently selected note and fills them into the input box.

- 输入框（Input Box）：显示 / 编辑代码，多个古琴标记用分号 ; 分隔。
- Input Box: Displays / edits codes. Separate multiple Guqin marks with a semicolon ;.

- 修改（Apply）：把输入框里的代码写回当前音符。
- Apply: Writes the codes in the input box back to the current note.

- 删除（Delete）：删除当前音符上的全部古琴标记。
- Delete: Deletes all Guqin marks on the current note.

- 一键删除全部古琴标记（Delete All Guqin Marks）：删除整份乐谱中所有本插件生成的古琴标记（只算一次撤销）。
- Delete All Guqin Marks: Deletes all Guqin marks generated by this plugin in the entire score (counts as only one undo step).

四、基本流程 / Basic Workflow

① 用鼠标点选一个音符；② 点“读取”看看它已有多少古琴标记；③ 在输入框里编辑代码（多个用 ; 分隔）；④ 点“修改”。
① Click a note; ② press Read to see its existing Guqin marks; ③ edit the codes in the input box (separate with ;); ④ press Apply.

若想新增古琴标记，可以直接在搜索框里搜索、在代码列表里点击条目，插件会自动追加到当前音符下方，不会覆盖已有古琴标记。
To add a Guqin mark, you can also search in the search box and click a code list item; the plugin appends it below the current note without overwriting existing Guqin marks.

【重要操作提示 / Important Notes】
1. 智能自动避让：如果您在同一音符上添加了多个古琴标记，插件会自动将它们合并成一个整体的多行文本，并开启 MuseScore 的自动避让功能。无论叠加多少个减字，都不会与五线谱的音符或符干发生重叠。
1. Smart auto-placement: If you add multiple Guqin marks to the same note, the plugin automatically merges them into one multiline text and enables MuseScore’s autoplace function. No matter how many JianZiPu characters are stacked, they will not overlap with notes or stems on the staff.

2. 常用标记列表并不是全部：搜索框下方的常用标记列表仅列出了常见组合与修饰符示例。如果你想输入其他复杂组合，可以直接在“输入框”中手动输入代码，点“修改”即可生效。
2. The Common Marks list is not exhaustive: the Common Marks list below the search box only shows common combinations and modifier examples. If you want to enter other complex combinations, you can manually enter the code in the Input Box and press Apply.

五、代码语法规律（Noto Qin Jianzipu 字体专属）/ Code Syntax Rules (Noto Qin Jianzipu Font)

新字体完全基于“基础字 + 修饰符”的拼装逻辑。每一字部都起于一个命令字符，如反斜杠 \、斜杠 /、横杠 - 等。
The new font is entirely based on a “base character + modifier” assembly logic. Each component starts with a command character, such as backslash \, slash /, dash -, etc.

1. 底部基础字（右手指法与弦数）
以反斜杠 \ 开头。后面可接 1-7 的数字（代表弦）和右手八法字母。
1. Bottom base characters (right-hand techniques and string numbers)
Start with a backslash \. It can be followed by digits 1–7 (string numbers) and letters for the eight right-hand techniques.

示例 / Examples:
\g  = 勾 / gou
\7g = 七弦勾 / gou on the 7th string
\4/d... 

2. 左手指法与音色（Top Characters）
以斜杠 / 或补字号 ^ 开头。
2. Left-hand finger techniques and tone colors (Top Characters)
Start with a slash / or a superscript marker ^.

示例 / Examples:
/g/s   = 勾 + 散音 / gou + open string
/g/da  = 勾 + 大指 / gou + thumb
/g^7   = 勾 + 上徽（第7徽） / gou + upper hui (7th hui)
/g/7   = 勾 + 下徽（第7徽） / gou + lower hui (7th hui)
/g/ch  = 勾 + 绰 / gou + chuo

3. 上下辅助符号（横杠 / 联号）
以横杠 - 开头，主要用于上下走向和中间/下面数字。
3. Upper/lower auxiliary symbols (dash / linking marks)
Start with a dash -. They are mainly used for upward/downward directions and middle/lower numbers.

示例 / Examples:
/g-s     = 勾 + 上 / gou + up
/g-x     = 勾 + 下 / gou + down
/g-z7    = 勾 + 中间数字 7 / gou + middle number 7
/g-6     = 勾 + 下面数字 6 / gou + lower number 6
/g-s-z7-6 = 组合：勾上七六 / combination: gou, up, seven, six

4. 组合减字（撮 / 反撮等）
将两个减字谱用 || 并在一起（中间不要加空格）。
4. Combined JianZiPu characters (cuo / fan-cuo, etc.)
Join two JianZiPu codes with || (do not add spaces in between).

示例 / Examples:
\1g||\2t = 撮（一弦勾 + 二弦挑） / cuo (gou on string 1 + tiao on string 2)
\1g|f\2t = 反撮（f 代表反撮标志） / fan-cuo (f represents the fan-cuo marker)

5. 综合示例：大指7徽6分勾7弦
代码：\7g/da/7^6
拆解：\7g（底部：七弦勾） + /da（大指） + /7（七徽） + ^6（六分）。不分先后顺序，字体会自动吸附到正确位置。
5. Comprehensive example: thumb, 7th hui, 6th fen, gou on the 7th string
Code: \7g/da/7^6
Breakdown: \7g (bottom: gou on the 7th string) + /da (thumb) + /7 (7th hui) + ^6 (6th fen). Order does not matter; the font automatically snaps each part into the correct position.

六、多个古琴标记的排列 / Multiple Guqin Marks

同一音符上的多个古琴标记会通过换行符 \n 自动合并成一个多行文本。读取后输入框会显示为 代码1; 代码2; 代码3。
Multiple Guqin marks on the same note are automatically merged into one multiline text via line breaks \n. After reading, the input box displays code1; code2; code3.

修改时按顺序一一对应，多余的会追加到下方，少于原有的会删除多余的。
When applying, codes correspond in order; extra codes are appended below, and if there are fewer codes than before, the extra existing marks are deleted.

由于启用了自动避让，所有文字会作为一个整体，自动避开五线谱上的其他元素，无需手动调整位置。
Because autoplace is enabled, all text is treated as a whole and automatically avoids other elements on the staff, so no manual positioning is needed.

七、搜索 / Search

在搜索框输入关键词即可过滤代码列表，支持中文和代码混合搜索；多个关键词用空格分隔，需同时包含（AND 逻辑）才会显示。
Enter keywords in the search box to filter the code list. Mixed Chinese and code search is supported. Separate multiple keywords with spaces; all keywords must be included (AND logic) for an item to be shown.

在搜索框按回车会直接插入第一条结果到当前音符。点“清空”重置搜索。
Press Enter in the search box to directly insert the first result into the current note. Click Clear to reset the search.

八、一键删除全部古琴标记 / Delete All Guqin Marks

点击“一键删除全部古琴标记”按钮，插件会扫描所有谱表、所有声部，找出字体为 Noto Qin Jianzipu 的全部古琴标记并一次性删除。此操作只记录为一次撤销，按一次 Ctrl+Z 即可全部恢复。
Click the “Delete All Guqin Marks” button. The plugin scans all staves and all voices, finds all Guqin marks whose font is Noto Qin Jianzipu, and deletes them at once. This operation is recorded as only one undo step; press Ctrl+Z once to restore them all.

九、外观参数 / Appearance Parameters

在插件源码顶部可以调整：markFont（字体名，默认 Noto Qin Jianzipu）、markFontSize（字号，默认 12）、markLineSpacing（多行文本行距，默认 1.2）、markOffsetY（第一个古琴标记距音符高度，默认 3.5）。
At the top of the plugin source code, you can adjust: markFont (font name, default Noto Qin Jianzipu), markFontSize (font size, default 12), markLineSpacing (multiline text line spacing, default 1.2), markOffsetY (vertical offset of the first Guqin mark from the note, default 3.5).

十、常见问题 / FAQ

Q：古琴标记显示成了英文字母或符号，没有变成减字谱图形？
A：这说明您的系统或软件未开启“合字（Ligatures）”特性，或者没有安装 Noto Qin Jianzipu 字体。请安装该字体。另外，输入的代码中间（除规定的连接符外）不要乱加空格。
Q: The Guqin mark is displayed as English letters or symbols instead of JianZiPu graphics.
A: This means ligatures are not enabled in your system or software, or the Noto Qin Jianzipu font is not installed. Please install the font. Also, do not add extra spaces inside the code (except for the specified connectors).

Q：输入代码后，旁边多出了奇怪的 `+` 号？
A：这是早期旧版插件的遗留数据。请点击“删除”后，重新在最新版插件中点击“修改”即可彻底清除。
Q: After entering the code, a strange `+` sign appears nearby.
A: This is leftover data from an early old version of the plugin. Click Delete, then click Apply again in the latest version of the plugin to remove it completely.

Q：多声部谱表里古琴标记会串到别的声部吗？
A：读取、修改、删除都以“当前音符所在的谱表 + 声部”为范围，不会影响其他声部；只有“一键删除全部古琴标记”会覆盖全谱。
Q: Will Guqin marks in a multi-voice staff leak into other voices?
A: Read, Apply and Delete all operate within the scope of “the staff + voice of the current note” and will not affect other voices. Only “Delete All Guqin Marks” covers the entire score.
