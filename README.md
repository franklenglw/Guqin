This plugin is used in MuseScore 3.6 to render Guqin notation marks. It uses the JianZiPu font (V3.2) from https://github.com/neuralfirings/JianZiPu. For usage instructions and copyright information, please refer to the manual and the LICENSE.

不知是这个版本的软件对于字体堆叠渲染的不支持还是什么原因，有些可以完美的渲染出来，有的则不行。鉴于这个插件是在win7 64位系统上开发的，其表现不是很令人满意。或许在win10的musescore4.x版本中能有所突破。

I'm not sure whether this version of the software does not support layered font rendering or whether it is due to some other reason—some marks render perfectly, while others do not. Given that this plugin was developed on a 64-bit Windows 7 system, its performance is not very satisfactory. Perhaps there may be some breakthrough in MuseScore 4.x on Windows 10.
